    Sugestões

    Cores mais próximas que passam, mudando só a luminosidade (o L do HSL) do texto ou do fundo. Valem para texto normal.

    Simulação de daltonismo

    Aproximação de como o par aparece para pessoas com cada tipo de deficiência de visão de cores (forma mais intensa).

    Modo paleta

    Linhas: cor do texto. Colunas: cor do fundo. AAA ≥ 7:1, AA ≥ 4,5:1, «AA grande» ≥ 3:1 (só texto grande e componentes).

    Como o contraste é calculado

    A WCAG compara a luminância relativa das cores: quanta luz cada uma emite, de 0 (preto) a 1 (branco). Cada canal sRGB é convertido para valor linear e os três são somados com pesos que seguem a sensibilidade do olho (0,2126 para o vermelho, 0,7152 para o verde e 0,0722 para o azul). A razão de contraste é (L1 + 0,05) / (L2 + 0,05), sendo L1 a cor mais clara. Vai de 1:1 (cores iguais) a 21:1 (preto no branco).

    • 1.4.3 Contraste (mínimo), nível AA: 4,5:1 para texto normal e 3:1 para texto grande.
    • 1.4.6 Contraste (melhorado), nível AAA: 7:1 para texto normal e 4,5:1 para texto grande.
    • 1.4.11 Contraste não textual, nível AA: 3:1 para componentes de interface (bordas de campos, ícones, indicador de foco) e partes de gráficos necessárias para entendê-los.

    Texto grande é o que tem pelo menos 18 pt (24 px) ou 14 pt (cerca de 18,66 px) em negrito. Texto de logotipos, puramente decorativo ou de componentes desabilitados não tem exigência de contraste.

    Cores com transparência: o texto é combinado com o fundo, e um fundo transparente é considerado sobre branco. A simulação de daltonismo usa as matrizes de Machado, Oliveira e Fernandes (2009) e é só uma aproximação.
